# Constitution Lab

**Sister project to the Federated Republic.**

> The Federated Republic shows what *one* complete constitutional design looks like. The Constitution Lab explores what constitutional design *can be*.

A neutral, modular, evidence-based studio for comparing institutions, examining historical choices, and designing alternative arrangements.

- **Neutrality**: No arrangement gets preference because the FR uses it.
- **Modularity**: Explore one institution at a time.
- **Evidence**: Real cases + historical outcomes inform the comparisons.

Live site: GitHub Pages ( `main` branch, root )

## Structure
```
/index.html                                # Landing — FR vs Lab
/explorer/head-of-government/index.html    # Playful 5-card compare + Break it
/explorer/head-of-government/adventure/index.html # Book 1: Choose-your-own-adventure
/explorer/head-of-government/data.json     # Structured content model
/assets/css/style.css                      # Shared Lab styles
```

## Head of Government — flow
1. **Adventure first** — 3 choices, rewind with different rules (“What if you were a President?”)
2. **Then compare** — same 5 lenses, trade-off bars, evidence snacks
3. **Your Architecture** — deterministic compatibility flags (no AI required)

Built to run entirely static. AI optional for “explain my weird combo.”
